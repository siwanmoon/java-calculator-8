# java-calculator-precourse
## 구현할 기능 목록

- [x] 커스텀 구분자 확인
- [x] 구분자를 기준으로 문자열을 분리
- [x] 아무것도 입력 안됐을시 0으로 인식
- [x] 구분한 문자열간의 덧셈 연산 실행

- ### 예외처리 (IllegalArgumentException 발생)

  - [x] 구분자가 아닌 문자가 입력된 경우

## 전제 조건

- 입력받은 문자열이 구분자로 시작하거나 끝난경우 0이 있는 것으로 가정
- 마찬가지로 문자열이 두개 이상 연속해서 존재한다면 0으로 인식

## 고려사항

- 숫자의 크기를 어디까지로 인정할 것인가
  1. int 범위를 넘어가는 숫자는 예외처리
  2. 실제 계산기와 유사하게 10자리 숫자까지 표기
  3. 자릿수 관계없이 입력받기
- 소수를 인식받을 것인가
  1. 소수를 인식받는다면 커스텀 구분자로 "//.\n"이 입력됐을 때 어떻게 처리할 것인가
