# java-calculator-precourse
## 구현할 기능 목록

- [x] 커스텀 구분자 확인
- [x] 구분자를 기준으로 문자열을 분리
- [x] 아무것도 입력 안됐을시 0으로 인식
- [x] 구분한 문자열간의 덧셈 연산 실행
- [x] 빈칸, 문자열도 커스텀 구분자로 사용 가능

- ### 예외처리 (IllegalArgumentException 발생)

  - [x] 구분자가 아닌 문자가 입력된 경우

## 전제 조건

- 입력받은 문자열이 구분자로 시작하거나 끝난경우 0이 있는 것으로 가정
 
  ex) ,:123 = 0,0:123
- long 값을 넘어갈 경우 오류 발생
- 소수점과 마이너스 부호가 커스텀 구분자로 사용될 수 있기 때문에 소수, 음수 연산은 미지원
- 커스텀 구분자가 선언만 하고 입력하지 않았을 경우 커스텀 구분자가 없는것으로 연산

  ex) //\n1:2 인경우 , 과 : 두개만 구분자로 사용
